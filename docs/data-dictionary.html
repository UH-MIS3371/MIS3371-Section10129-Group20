Status History Log

Every status change is saved as its own row in a separate log, so each referral keeps a full history of who changed it, when, and why. The main record above holds only the current status.

Form Mapping

  • Entered on the form: patientId, referringProviderId, referralDate, requestedService, urgency, referralReason
  • Shown on the page as a message: receivingDepartment (appears under Requested Service)
  • Set later in the workflow (not on this form): referralId, status, submittedAt, updatedAt, reviewedBy, decisionReason, scheduledDate, overdueFlag

Notes

referralId, status, submittedAt, and updatedAt cover the required transaction ID, status field, and two timestamps. User-entered fields come from the form; derived fields are calculated from other data; system-assigned fields are generated by the system with no user input.
