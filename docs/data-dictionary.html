Status History Log

Every status change is saved as its own row in a separate log, so each referral keeps a full history of who changed it, when, and why. The main record above holds only the current status.

Notes

referral_id, status, submitted_at, and updated_at cover the required transaction ID, status field, and two timestamps. User-entered fields come from the form; derived fields are calculated from other data; system-assigned fields are generated by the system with no user input.
